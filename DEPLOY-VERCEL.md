# Front-end Eleições Digitais

O `app.js` usa a API `https://eleicoesdigitais-back.vercel.app/api` para carregar candidaturas e propostas, registrar votos e consultar resultados.

Publique esta pasta no host do front-end. Após publicar, faça um hard refresh (Ctrl+F5). Se o site já foi instalado como PWA, feche e reabra ou limpe os dados/cache do site para atualizar o Service Worker.

Para que o envio de votos funcione, o backend precisa estar configurado com as variáveis do Supabase descritas no `DEPLOY-VERCEL.md` do projeto backend.
